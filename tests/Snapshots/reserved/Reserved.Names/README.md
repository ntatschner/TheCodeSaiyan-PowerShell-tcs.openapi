# Reserved.Names

PowerShell module for Reserved Names API (API version 2.1), generated by
[tcs.openapi](https://github.com/ntatschner/TheCodeSaiyan-PowerShell-tcs.openapi) 0.3.1.

## Getting started

```powershell
Import-Module ./Reserved.Names
Set-ReservedNamesContext -BaseUri 'https://api.example.com'
Get-Command -Module Reserved.Names
```

Every command has help (`Get-Help <command> -Full`). Commands pass `-Verbose`, `-Debug` and
`-ErrorAction` through to the request engine (`Invoke-OpenApiRequest` in tcs.openapi). Commands that
can change data also have `-WhatIf` and `-Confirm`; `Get-` and `Test-` commands do not.

## Changing the module

The files in `Public/`, `OpenApi/`, the manifest and the root module are generated: regenerate them
with `New-OpenApiModule ... -Force`. Put your own changes in `Overrides.ps1`, which is created once
and never overwritten; a function defined there replaces the generated command with the same name.
