TOPIC
    about_PetStore

SHORT DESCRIPTION
    PowerShell commands for Swagger Petstore (API version 1.0.0), generated by
    tcs.openapi.

LONG DESCRIPTION
    A sample API that uses a petstore as an example.

    Every command calls one operation of the API through Invoke-OpenApiRequest
    from tcs.openapi, which handles authentication, retry, paging and errors.
    Get-Help <command> -Full shows the operation each command calls.

CONNECTING
    Set the connection once per session (add -Persist to keep it for later
    sessions):

        Set-PetStoreContext -BearerToken (Read-Host -AsSecureString -Prompt 'Token')

    Get-PetStoreContext shows the connection and Remove-PetStoreContext
    removes it.

COMMANDS
    Get-PetStoreContext
        Get the connection used by the commands of this module.
    Get-PetStoreHealth
    Get-PetStoreInventory
        Returns pet inventories by status
    Get-PetStorePet
        List all pets
    Get-PetStorePetById
        Info for a specific pet
    Get-PetStorePetPhoto
        Download the photo of a pet
    Measure-PetStatistic
        Pet statistics
    New-PetStorePet
        Create a pet
    Remove-PetStoreContext
        Remove the connection used by the commands of this module.
    Remove-PetStorePet
        Delete a pet
    Set-PetStoreContext
        Set the connection used by the commands of this module.
    Set-PetStorePet
        Replace a pet

CHANGING THE MODULE
    The commands are generated by tcs.openapi 0.3.0. Regenerate
    them with New-OpenApiModule ... -Force. Put your own changes in
    Overrides.ps1, which is never overwritten; a function defined there
    replaces the generated command with the same name.
