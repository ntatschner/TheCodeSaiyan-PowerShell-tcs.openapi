# PetStore

PowerShell module for Swagger Petstore (API version 1.0.0), generated by
[tcs.openapi](https://github.com/ntatschner/TheCodeSaiyan-PowerShell-tcs.openapi) 0.1.1.

A sample API that uses a petstore as an example.

## Getting started

```powershell
Import-Module ./PetStore
Set-PetStoreContext -BearerToken (Read-Host -AsSecureString -Prompt 'Token')
Get-Command -Module PetStore
```

Every command has help (`Get-Help <command> -Full`). Commands pass `-Verbose`, `-Debug`,
`-ErrorAction` and `-WhatIf` through to the request engine (`Invoke-OpenApiRequest` in tcs.openapi).

## Changing the module

The files in `Public/`, `OpenApi/`, the manifest and the root module are generated: regenerate them
with `New-OpenApiModule ... -Force`. Put your own changes in `Overrides.ps1`, which is created once
and never overwritten; a function defined there replaces the generated command with the same name.
